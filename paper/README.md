# Paper files

- `Scotty-1_ESANN_paper.pdf` is the separately versioned six-page paper with the
  public model name and matching PDF title metadata.
- `Scotty-1_ESANN_LaTeX_source.zip` and `source/` contain its buildable source.
- `original/` preserves the exact delivered Beam-1 PDF and source ZIP for
  provenance. Their hashes are recorded in `provenance/artifacts.json`.

Only the model name was substituted in the manuscript title/model macro and
metadata. Numerical claims were not changed. References to the Reflection Beam
teacher remain Beam references.
